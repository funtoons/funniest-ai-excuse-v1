One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

`main.py` (stdlib only, deterministic, offline) writes the single excuse line to `/output/entry.txt`.

## The line

> I did finish on time, then my context window forgot the deadline, the task, and — honestly — most of you.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
